# HQ Simple — Brand Guidelines

This repository is the source of truth for the HQ Simple brand: logo, colors,
typography, and voice. Use the latest assets here rather than older copies.

## The name

The brand is **HQ Simple**. Write it as two words with both words capitalized.
Don't write "HQSimple," "Hq Simple," or "hqsimple" in body copy.

## Logo

The mark combines an "HQ" monogram with the "SIMPLE" wordmark. Use the supplied
SVG wherever possible and keep clear space around it equal to the height of the
"HQ" mark.

**Don't:**
- Recolor the logo outside the approved palette
- Stretch, skew, or rotate it
- Add shadows, gradients, or outlines
- Place it on a low-contrast background

## Colors

| Role            | Hex       | Notes                                  |
| --------------- | --------- | -------------------------------------- |
| Ink / Navy      | `#1A2430` | Primary text & dark surfaces           |
| White           | `#FFFFFF` | Primary background                     |
| Off-white       | `#FAFAF7` | Alternate section background           |
| Lime (accent)   | `#CFF300` | Highlights, tags, link underlines      |
| Olive Lime      | `#A8D117` | Deeper accent / hover state            |
| Pale Lime       | `#F3FACB` | Tinted card backgrounds                |

Use lime sparingly — as a "highlighter" behind key words and on small tags,
never as a large fill.

## Typography

- **Headings:** Inter Tight — heavy weight, tight tracking, large sizes
- **Body:** Inter
- **Labels / eyebrows:** JetBrains Mono — uppercase, letter-spaced

## Voice & tone

Direct, plain-spoken, human, and a little contrarian. Short declarative
sentences. Lead with the "we do the opposite" contrast against automated,
self-service competitors. Honest and transparent over corporate.

**Tagline:** "A real EOR. Not a SaaS in disguise."
